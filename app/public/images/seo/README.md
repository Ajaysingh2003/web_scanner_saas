# Scanlyst production images

The active assets live directly in `public/`, so each file is available from the
site root (for example, `/scanlyst-logo-512.png`).

- `scanlyst-logo-512.png` — app manifest, browser icons, and organization schema.
- `scanlyst-og-default.png` — default Open Graph sharing image.
- `scanlyst-twitter-card.png` — default X/Twitter sharing image.
- `scanlyst-dashboard-overview.webp` — primary homepage product screenshot.
- `scanlyst-security-report.webp` — homepage security evidence screenshot.
- `scanlyst-scan-progress.webp` — homepage scan progress screenshot.
- `scanlyst-monitoring-alerts.webp` — homepage monitoring screenshot.
- `scanlyst-pricing-preview.webp` — pricing page preview and social image.

All visible screenshots are rendered with responsive sizing and descriptive alt
text. Keep them visually accurate whenever the interface changes.
